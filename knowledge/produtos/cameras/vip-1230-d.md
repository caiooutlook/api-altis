# Câmera IP Dome VIP 1230 D

## Visão Geral

A VIP 1230 D é uma câmera IP dome compacta com resolução Full HD (2MP) e infravermelho inteligente, ideal para monitoramento de ambientes internos e externos com proteção IP67.

## Especificações Técnicas

| Característica | Valor |
|---|---|
| Resolução | 2 Megapixels (1920x1080) |
| Lente | 2.8mm fixa |
| Ângulo de visão | 112° |
| Compressão | H.265 / H.264 |
| IR inteligente | Até 30 metros |
| Proteção | IP67 (resistente a água e poeira) |
| Alimentação | PoE (802.3af) ou 12V DC |
| Consumo máximo | 8W |
| Temperatura operação | -30°C a 60°C |
| Dimensões | Ø 111 x 87mm |

## Recursos Principais

- **Infravermelho inteligente (Smart IR):** Ajusta automaticamente a intensidade do IR conforme a distância do objeto, evitando superexposição.
- **WDR Digital:** Compensação de contraluz para cenas com grande variação de luminosidade.
- **Detecção de movimento:** Configurável por zonas com sensibilidade ajustável.
- **Multistreaming:** Até 3 streams simultâneos com resoluções independentes.
- **ONVIF Profile S:** Compatível com gravadores e softwares de terceiros.
- **Análise inteligente:** Cerca virtual e detecção de intrusão.

## Instalação

### Requisitos
- Cabo de rede Cat5e ou superior (máx. 100m)
- Switch PoE ou fonte 12V DC
- Gravador NVR compatível (recomendado: NVD 1232 ou superior)

### Passo a Passo

1. **Fixação mecânica:** Utilize o gabarito de furação incluso para marcar os pontos na superfície. Fixe a base com os parafusos e buchas fornecidos.
2. **Conexão de rede:** Conecte o cabo de rede à porta RJ-45 da câmera. Se usar PoE, a alimentação será fornecida pelo mesmo cabo.
3. **Acesso inicial:** A câmera obtém IP via DHCP por padrão. Use o software **Intelbras IP Utility** para localizá-la na rede.
4. **Configuração via browser:** Acesse o IP da câmera via navegador web. Login padrão: `admin` / `admin` (altere na primeira utilização).
5. **Ajuste de imagem:** Regule o foco e a posição da dome soltando os parafusos do mecanismo 3-eixos.

## Configuração de Gravação

### Com NVR Intelbras (NVD)
1. Acesse o menu do NVR → **Câmeras** → **Adicionar**
2. A câmera será detectada automaticamente na mesma rede
3. Confirme e configure o perfil de gravação (contínuo ou por detecção)

### Stream principal vs. Extra
- **Stream principal:** Use 1080p@25fps para gravação em alta qualidade
- **Stream extra:** Use 640x360@15fps para visualização remota (economiza banda)

## Resolução de Problemas

| Problema | Causa Provável | Solução |
|---|---|---|
| Câmera não encontrada na rede | Cabo ou PoE sem conexão | Verifique LEDs do switch e da câmera |
| Imagem escura à noite | IR desativado | Ative o modo IR em Configurações → Imagem → Dia/Noite |
| Imagem borrada | Lente fora de foco | Ajuste o foco girando o anel da dome |
| Perda de conexão intermitente | Cabo de rede com problema | Substitua o cabo ou teste com outro path |

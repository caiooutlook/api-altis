# Câmera IP Bullet VIP 3230 B

## Visão Geral

A VIP 3230 B é uma câmera IP bullet da linha profissional com WDR real (120dB), inteligência de vídeo embarcada e proteção IP67. Projetada para monitoramento externo em condições desafiadoras de iluminação.

## Especificações Técnicas

| Característica | Valor |
|---|---|
| Resolução | 2 Megapixels (1920x1080) |
| Sensor | 1/2.8" Progressive Scan CMOS |
| Lente | 3.6mm fixa |
| Ângulo de visão | 103° |
| WDR | Real 120dB |
| Compressão | H.265+ / H.265 / H.264 |
| IR inteligente | Até 30 metros |
| Proteção | IP67 |
| Alimentação | PoE (802.3af) ou 12V DC |
| Slot cartão SD | Até 256GB (gravação local) |

## Recursos de Inteligência de Vídeo

A VIP 3230 B possui análises inteligentes embarcadas no firmware:

- **Detecção de face:** Identifica a presença de rostos no campo de visão e gera snapshots automáticos.
- **Cerca virtual (tripwire):** Alarme ao cruzar uma linha virtual definida pelo usuário.
- **Detecção de intrusão:** Alarme ao entrar/permanecer em zona delimitada.
- **Detecção de abandono de objeto:** Identifica objetos deixados na cena por tempo configurável.
- **Detecção de remoção de objeto:** Identifica quando um objeto é retirado da cena.
- **Contagem de pessoas:** Conta entradas/saídas em uma linha de referência.

## Configuração da Inteligência de Vídeo

### Cerca Virtual (Tripwire)

1. Acesse **Configurações → Evento → Análise Inteligente → Tripwire**
2. Habilite a função e desenhe a linha no preview da imagem
3. Selecione a direção de detecção (A→B, B→A ou ambas)
4. Configure a ação: gravar, snapshot, alarme sonoro ou enviar e-mail
5. Defina a agenda (horários em que a regra está ativa)

### Detecção de Intrusão

1. Acesse **Configurações → Evento → Análise Inteligente → Intrusão**
2. Desenhe até 4 zonas poligonais no preview
3. Configure sensibilidade (1-100, recomendado: 50)
4. Configure tempo mínimo de permanência (em segundos)
5. Defina as ações de resposta

## Instalação

### Posicionamento recomendado
- Altura: 2,5m a 3,5m do solo
- Inclinação: 15° a 30° para baixo
- Evite apontar diretamente para fontes de luz forte

### Conexão
- Use cabo UTP Cat5e ou Cat6
- Distância máxima: 100m (com PoE)
- Para distâncias maiores: use extensor PoE ou fibra óptica com conversor

## Gravação em Cartão SD (Edge Recording)

A câmera pode gravar localmente em cartão SD como redundância:

1. Insira o cartão SD no slot lateral (com a câmera desligada)
2. Acesse **Configurações → Armazenamento → Gerenciar → Formatar**
3. Configure em **Gravação Local** os parâmetros de stream e agenda
4. A gravação local ativa automaticamente se perder conexão com o NVR

## WDR (Wide Dynamic Range)

O WDR real de 120dB combina múltiplas exposições para equilibrar áreas claras e escuras na mesma cena. Ideal para:

- Entradas de prédios (contraluz forte)
- Estacionamentos com iluminação irregular
- Portarias com vidro e área externa visíveis simultaneamente

Para ativar: **Configurações → Imagem → WDR → Nível** (ajuste de 1 a 100).

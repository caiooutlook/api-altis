# Central de Alarme AMT 8000

## Visão Geral

A AMT 8000 é a central de alarme topo de linha da Intelbras para aplicações profissionais e empresariais. Suporta até 64 zonas (com e sem fio), comunicação IP via Ethernet/Wi-Fi, monitoramento por empresa de segurança e controle total via aplicativo.

## Especificações Técnicas

| Característica | Valor |
|---|---|
| Zonas com fio | 8 na placa (expansível até 64) |
| Zonas sem fio | Até 64 (sensores 433 MHz) |
| Partições | 4 partições independentes |
| Usuários | Até 64 (senha ou controle remoto) |
| Saídas PGM | 4 na placa (expansível até 16) |
| Comunicação | Ethernet, Wi-Fi, linha telefônica, GPRS (opcional) |
| Protocolo monitoramento | Contact ID (IP e linha) |
| Alimentação | 16.5V AC (transformador incluso) |
| Bateria backup | 12V 7Ah (autonomia ~24h) |
| Teclado | Até 4 teclados XAT 8000 |

## Conceitos Importantes

### Zonas
Uma **zona** é um ponto de detecção (ex: um sensor de abertura na porta, um sensor de movimento na sala). Cada zona pode ser configurada com atributos:
- **Imediata:** Dispara alarme instantaneamente ao ser violada
- **Temporizada:** Permite tempo de entrada/saída (ex: porta principal)
- **Seguidora:** Temporizada somente se uma zona temporizada foi acionada antes
- **24 horas:** Sempre ativa, independente do sistema estar armado (ex: sensor de fumaça)
- **Silenciosa:** Envia evento para central de monitoramento sem disparar sirene

### Partições
Dividem a central em setores independentes. Exemplo em empresa:
- Partição 1: Recepção e loja (desarma durante horário comercial)
- Partição 2: Estoque (sempre armada exceto acesso autorizado)
- Partição 3: Escritório administrativo
- Partição 4: Área externa / perímetro

## Instalação

### Fiação dos sensores (zonas com fio)

1. **Sensor de abertura magnético:** Conecte os fios do sensor à zona correspondente no barramento. Use resistor de fim de linha (2.2kΩ) para detecção de tamper.
2. **Sensor de movimento (IVP):** Alimente com 12V da saída AUX da central. Conecte o contato NA/NF à zona desejada.
3. **Topologia:** Use conexão em estrela (cada sensor com cabo dedicado até a central) para facilitar manutenção.

### Conexão de rede

1. Conecte um cabo Ethernet na porta RJ-45 da central
2. Por padrão, usa DHCP. Para IP fixo: configure via teclado ou software Intelbras Programador
3. Para Wi-Fi: acesse as configurações via software e insira SSID e senha da rede

## Programação

### Via Teclado XAT 8000

1. Entre no modo programação: `ENTER + SENHA MASTER + ENTER`
2. Navegue pelos menus com as teclas de seta
3. Comandos comuns:
   - Alterar senha master: Menu → Senhas → Master → nova senha
   - Programar zona: Menu → Zonas → selecione zona → configure atributos
   - Configurar PGM: Menu → PGM → selecione saída → defina ação

### Via Software Intelbras Programador

1. Instale o software (download em intelbras.com.br)
2. Conecte via Ethernet (mesma rede da central) ou USB
3. Interface gráfica permite configurar todas as zonas, partições, usuários e comunicação
4. **Recomendado para programação completa** — muito mais rápido que via teclado

## Monitoramento por Empresa de Segurança

### Configuração Contact ID via IP

1. Acesse a programação de comunicação
2. Configure o IP/porta do servidor da empresa de monitoramento
3. Defina a conta do cliente (4 dígitos)
4. Configure quais eventos serão reportados (arrombamento, pânico, falha, etc.)
5. Teste a comunicação com a central de monitoramento

### Eventos reportados
- Abertura/fechamento do sistema
- Disparo de alarme por zona
- Pânico (audível ou silencioso)
- Falha de alimentação AC
- Bateria fraca
- Tamper (violação de sensor ou central)

## Controle via Aplicativo (AMT Mobile)

1. Habilite o **Intelbras Cloud** na central (via programação de rede)
2. No celular, instale o app **AMT Mobile V3**
3. Adicione a central usando o MAC address (etiqueta) ou QR code
4. Funcionalidades disponíveis:
   - Armar/desarmar (total ou por partição)
   - Visualizar status de zonas em tempo real
   - Receber notificações push de eventos
   - Histórico de eventos
   - Ativar/desativar saídas PGM (ex: portão, iluminação)

## Resolução de Problemas

| Problema | Causa | Solução |
|---|---|---|
| Zona sempre aberta | Sensor mal instalado ou fio rompido | Verifique continuidade com multímetro |
| Central não comunica via IP | Sem conexão de rede | Verifique cabo, IP, e se Cloud está habilitado |
| Falso alarme em IVP | Sensibilidade alta ou animal | Ajuste sensibilidade ou use sensor pet-friendly |
| Sirene não dispara | PGM de sirene não configurada | Verifique programação da saída de sirene |
| Bateria fraca constante | Bateria antiga ou defeituosa | Substitua por bateria 12V 7Ah nova |

# Fechadura Digital ELC 5001 RF

## Visão Geral

A ELC 5001 RF é uma fechadura digital inteligente com múltiplos métodos de abertura: biometria (digital), senha numérica, cartão RFID e aplicativo via Bluetooth. Ideal para residências e escritórios que desejam eliminar chaves convencionais.

## Especificações Técnicas

| Característica | Valor |
|---|---|
| Métodos de abertura | Biometria, senha, cartão RFID, app Bluetooth, chave mecânica |
| Capacidade biometria | Até 100 digitais |
| Capacidade senhas | Até 50 senhas (4-8 dígitos) |
| Capacidade cartões | Até 100 cartões RFID (13.56 MHz) |
| Tipo de porta | Pivotante ou de correr (com adaptador) |
| Espessura da porta | 35mm a 65mm |
| Material | Liga de zinco + acabamento escovado |
| Alimentação | 4x pilhas AA (autonomia ~8 meses) |
| Alimentação emergência | Micro-USB 5V (externo) |
| Conectividade | Bluetooth 4.0 |

## Métodos de Abertura

### 1. Biometria (Digital)

Sensor capacitivo semicondutor com detecção 360° — funciona independente da orientação do dedo.

- **Tempo de reconhecimento:** < 0.5 segundos
- **Taxa de falsa aceitação (FAR):** < 0.001%
- **Taxa de falsa rejeição (FRR):** < 1%
- **Dica:** Cadastre 2-3 posições do mesmo dedo para melhor reconhecimento

### 2. Senha Numérica

- Suporta **senha virtual:** digite números aleatórios antes e depois da senha real (anti-espionagem)
- Exemplo: senha é `1234`, pode digitar `8751234369` — a fechadura encontra a sequência correta
- **Bloqueio:** Após 5 tentativas erradas, bloqueia por 3 minutos

### 3. Cartão RFID

- Frequência: 13.56 MHz (Mifare)
- Basta aproximar o cartão do leitor frontal
- Cartões adicionais são cadastrados via menu master

### 4. Aplicativo Bluetooth

- App: **Intelbras Smart i1** (Android/iOS)
- Alcance: ~10 metros (sem obstáculos)
- Funcionalidades: abrir porta, cadastrar usuários, ver histórico, gerar chaves temporárias

## Instalação

### Compatibilidade de porta
- Portas de madeira, metal ou vidro com moldura
- Espessura: 35mm a 65mm
- A porta deve ter furo padrão de fechadura cilíndrica ou ser adaptada

### Passo a passo

1. **Remova a fechadura antiga** e limpe os furos existentes
2. **Verifique o gabarito:** Use o gabarito incluso para confirmar a posição dos furos
3. **Instale a parte interna:** Passe os cabos pelo furo central, fixe com parafusos
4. **Instale a parte externa:** Conecte os cabos ao módulo externo, fixe
5. **Insira as pilhas** no compartimento interno
6. **Primeiro acesso:** O sistema pedirá para cadastrar o administrador master (digital + senha)

### Sentido de abertura
A fechadura detecta automaticamente se a porta abre para dentro ou para fora. Caso não detecte, ajuste manualmente no menu de configuração.

## Configuração de Usuários

### Cadastro via fechadura

1. Toque no painel → digite a **senha master** → confirme
2. Menu: **Adicionar Usuário**
3. Escolha o método (digital, senha ou cartão)
4. Siga as instruções no display/áudio
5. O usuário recebe um número de ID (01-100)

### Cadastro via aplicativo

1. Abra o app **Intelbras Smart i1**
2. Conecte-se à fechadura via Bluetooth
3. Vá em **Gerenciar → Adicionar usuário**
4. Escolha o tipo e siga as instruções
5. Pode gerar **chaves temporárias** com validade (ex: para diarista)

## Recursos de Segurança

- **Alarme de violação:** Se alguém tenta forçar a fechadura, dispara alarme sonoro de 90dB
- **Modo pânico:** Cadastre uma digital específica como "digital de pânico" — abre a porta mas envia alerta silencioso
- **Bloqueio automático:** Porta tranca automaticamente ao fechar (ajustável)
- **Registro de acessos:** Armazena os últimos 200 eventos com data/hora e ID do usuário
- **Sensor de porta aberta:** Alerta se a porta ficar aberta por mais de 30 segundos

## Manutenção

- **Troca de pilhas:** Quando o alerta de bateria fraca soar, troque as 4 pilhas AA. Todos os cadastros são mantidos.
- **Limpeza do sensor:** Use pano seco e macio. Não use álcool ou produtos químicos no sensor biométrico.
- **Emergência sem bateria:** Use uma fonte USB 5V no conector micro-USB externo (abaixo do painel frontal) para alimentar temporariamente e desbloquear.
- **Chave mecânica:** Último recurso — a chave mecânica fica escondida sob uma tampa na parte inferior do painel externo.

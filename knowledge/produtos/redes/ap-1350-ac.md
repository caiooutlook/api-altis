# Access Point AP 1350 AC

## Visão Geral

O AP 1350 AC é um access point corporativo de teto dual band (2.4 GHz + 5 GHz) com velocidade combinada de 1350 Mbps. Projetado para ambientes empresariais com muitos dispositivos simultâneos, suporta gerenciamento centralizado via controladora WiseFi.

## Especificações Técnicas

| Característica | Valor |
|---|---|
| Padrão Wi-Fi | 802.11ac Wave 2 |
| Velocidade 2.4 GHz | Até 450 Mbps |
| Velocidade 5 GHz | Até 900 Mbps |
| Antenas | 3x3 MIMO internas |
| Clientes simultâneos | Até 200 |
| SSIDs | Até 16 (8 por banda) |
| PoE | 802.3at (PoE+) |
| Porta | 1x Gigabit Ethernet |
| Montagem | Teto (suporte incluso) |

## Cenários de Uso

- **Escritórios corporativos:** Cobertura de open offices com alta densidade de dispositivos
- **Hotéis e pousadas:** Guest Wi-Fi com captive portal personalizado
- **Escolas e universidades:** Múltiplas VLANs para alunos, professores e administrativo
- **Varejo:** Wi-Fi para clientes e operação interna separados

## Gerenciamento Centralizado (WiseFi)

O WiseFi é a plataforma de gerenciamento em nuvem da Intelbras para redes corporativas:

1. Acesse `https://wisefi.intelbras.com.br`
2. Crie uma conta e adicione sua organização
3. Cadastre os APs pelo número de série
4. Gerencie todos os APs de um dashboard centralizado:
   - Configuração em massa de SSIDs
   - Mapa de calor de cobertura
   - Monitoramento de clientes conectados
   - Atualizações de firmware remotas
   - Alertas e relatórios

## Configuração Stand-alone

Se não usar o WiseFi, cada AP pode ser configurado individualmente:

1. Conecte o AP via PoE a um switch compatível
2. O AP obtém IP via DHCP
3. Use o software **Intelbras AP Config** para descobrir o AP na rede
4. Acesse via browser → login padrão: `admin` / `admin`
5. Configure SSIDs, segurança, VLANs e canais manualmente

## Resolução de Problemas

| Problema | Solução |
|---|---|
| AP não liga via PoE | Confirme que o switch suporta 802.3at (não apenas .3af) |
| Baixa velocidade | Verifique interferência no canal. Use DFS em 5GHz se disponível |
| Clients desconectam | Ajuste roaming (802.11r/k/v) e potência de transmissão |
